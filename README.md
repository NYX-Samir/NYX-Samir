# About Me

Hi, I'm **Abdul Samir**, a Computer Science undergraduate focused on **applied AI and LLM systems**.  
My work centers on building **end-to-end Retrieval-Augmented Generation (RAG) pipelines**, fine-tuning transformer models, and deploying AI services using **FastAPI and Docker**.

I’m particularly interested in the engineering side of Generative AI — retrieval, evaluation, system design, and deployment — rather than purely theoretical research.
